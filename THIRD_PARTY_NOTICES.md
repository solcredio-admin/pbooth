The visual language (glass recipe, keycap hover, intro choreography) is adapted from the author's
own portmap project. The look of liquid glass is borrowed in CSS from dashersw/liquid-glass-js (MIT);
its runtime is not used. paper-design/liquid-logo (PolyForm Shield) is **not** used; only the
Apache-2.0 shader package is.

Font licence texts ship inside the `@fontsource-variable/*` packages (LICENSE files).
